# Why the assessment office has no front end

The office's work is reviewing records, joining evidence and preparing papers. Ask Claude Code, Codex, OpenCode or Cursor to run the CLI. Two branded read-only views show the assessment week and the evidence gaps. Four document types produce the paper, marking guide, moderation pack and validation record.

A screen adds candidate sign-in, online timed tests, drag-and-drop question editing, mobile collection, offline synchronisation and live proctoring. This base does none of those. It is useful for a paper-based assessment office or for the review work around results exported from a delivery system. Enterprise DNA can scope a delivery interface and integrations separately. No claim is made that the base replaces a high-stakes testing platform end to end.

Generated files are private working documents. Candidate papers omit rubrics, while the marking guide carries them and stays with staff. Readiness problems stay visible. A person controls every issue, assessment judgement and communication.
